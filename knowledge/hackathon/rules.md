# QNX Global Hackathon - rules & dates

- URL: https://qnx.devpost.com/
- Rules page: https://qnx.devpost.com/rules
- Dates page: https://qnx.devpost.com/details/dates

## Key dates (verified 2026-11-13)

- Submissions open: **November 02, 2026, 11:00am EST**
- Deadline: **December 15, 2026, 2:00pm EST**
- Public voting / judging: January 15 - January 29, 2027
- Winners announced: February 04, 2027

## Hard constraints (submission checklist)

- [ ] Project runs on or targets QNX 8.0 (QNX Everywhere); QEMU or any supported
      hardware (incl. Raspberry Pi 4/5) is acceptable
- [ ] Repo created during the submission period, public, open-source licensed;
      license visible in the repo About section
- [ ] Repo contains all source, assets, build & run instructions
- [ ] Evidence the project actually builds/runs for QNX 8.0 (naming QNX is not enough)
- [ ] Build/run instructions state QNX version, target (HW or QEMU) and toolchain
- [ ] Project description names the files/functions/outputs that show the QNX connection
- [ ] Demo video under 3 minutes, public on YouTube, no unauthorized third-party
      marks or copyrighted music
- [ ] QNX SDP files (licensed) never committed to the repo or public CI
- [ ] Single category selected; bonus targets: Best use of QNX-specific technologies
      ($3,500), optionally Best Codelab / Tutorial
