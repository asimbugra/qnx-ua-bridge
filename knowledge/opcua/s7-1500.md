# Siemens S7-1500 as an OPC UA server

Verified from Siemens TIA documentation, 2026-11-13.

## Server availability & licensing

- S7-1500 CPUs have a built-in OPC UA server; running it requires a purchased
  **runtime license** keyed to CPU class:
  - SIMATIC OPC UA S7-1500 small: CPU 1511/1512/1513, ET 200SP CPUs, CPU 1515SP PC
  - medium: CPU 1515/1516, CPU 1507 software controller, CPU 1516pro-2PN
  - large: CPU 1517/1518
- License type is shown in TIA Portal under CPU Properties > General > Runtime
  licenses > OPC UA.
- Source: docs.tia.siemens.cloud - "License for OPC UA" (Communication function manual).

## Address space shape

- Server capabilities monitored/based on method access; tags exposed per DB with
  HMI access enabled.
- Node ids commonly look like `ns=3;s="DataBlockDB".TagName` (namespace index
  assigned by the project; string ids from the DB structure). Exact ns index must
  be discovered by browsing - that is what tools/tagmap-gen automates.

## Implication for this project

- A real S7-1500 is NOT required for the hackathon: the runtime license + TIA
  Portal setup is heavy, and access to factory PLCs needs explicit permission.
- tools/plc-sim mirrors the S7-1500 shape: server namespace with
  `ns=3;s="<DB>".<Tag>` string ids, doubles/bools/ints, read+write.
- If a real PLC becomes available later (with explicit owner permission), the same
  tests re-run unchanged because the bridge only sees OPC UA.
